移动端固定下导航（SVG 图标）

使用 font/ 目录 iconfont 的 SVG Symbol 形式制作同一个下导航。图标作为内联 SVG，通过 <use> 引用，颜色由 currentColor 决定，矢量缩放更清晰。

页面效果

导航结构与字体版完全一致，只是图标改为 SVG 渲染，固定在底部并随容器自适应宽度。

SVG 图标优点：矢量清晰、可多色、可用 CSS 精细控制；缺点：图标多时 SVG 体积较大。
