异步操作：包饺子流程

包饺子的流程是典型的异步任务：买原料、取原料必须依次进行； 和面、拌馅互不依赖，可以同时进行（Promise.all）； 两样都好了才能包饺子，包完才能吃 —— 这就是 await 的串行控制。 每一步都用 setTimeout 模拟耗时，点击按钮观看流程执行。

去市场买面粉、韭菜、猪肉 · 约需 6 秒

2. 取原料 等待中

二、两种代码写法

写法 1 · async / await（推荐，像同步代码一样好读）

async function sy_baoJiaoZi() {
  await sy_step("买原料", 6000);          // 必须先买，串行等待
  await sy_step("取原料", 2000);
  await Promise.all([                     // 和面、拌馅同时进行
    sy_step("和面", 4000),
    sy_step("拌馅", 3000)
  ]);                                     // 两个都完成才继续往下走
  await sy_step("包饺子", 5000);
  await sy_step("吃饺子", 3000);
}

写法 2 · Promise 链（.then 串起来）

sy_step("买原料", 6000)
  .then(() => sy_step("取原料", 2000))
  .then(() => Promise.all([              // 并行：两个都 resolve 才进入下一个 then
      sy_step("和面", 4000),
      sy_step("拌馅", 3000)
  ]))
  .then(() => sy_step("包饺子", 5000))
  .then(() => sy_step("吃饺子", 3000));

每一步的本质：用 Promise 包装 setTimeout

function sy_step(sy_name, sy_ms) {
  return new Promise(function (sy_resolve) {   // 把 setTimeout 变成 Promise
    setTimeout(function () {
      sy_resolve(sy_name);                    // 时间到，任务完成
    }, sy_ms);
  });
}

关键点：① await 会等待 Promise 完成再执行下一行； ② Promise.all 等所有并行任务都完成才 resolve，本例并行阶段总耗时 = max(4, 3) = 4 秒而不是 7 秒； ③ async 函数本身也返回 Promise，可以用 .then 接住它的结果。
