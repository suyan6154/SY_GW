CSS length units

Web 前端长度单位

CSS 长度单位用来设置宽度、间距、字号等尺寸。常见单位可分为绝对长度和相对长度，调整窗口大小观察示例变化。

绝对长度单位

尺寸不依赖父元素或视口。网页布局中最常用的是 px；物理单位通常用于打印场景。

px 像素

160px：屏幕设计中常用的固定尺寸。

in 英寸

2in：物理长度单位；CSS 中 1in 等于 96px。

cm、mm、pt、pc

其他物理单位：厘米、毫米、磅、派卡。1pt 等于 1/72in，1pc 等于 12pt。

字体与容器相对单位

尺寸会参照当前字体大小或父级容器，适合构建灵活、易缩放的布局。

em

此示例字号为 20px，宽度 10em = 200px。

rem

参照根元素字号；默认根字号为 16px，宽度 10rem = 160px。

% 百分比

相对于包含块的对应尺寸；色条宽度为容器的 60%。

视口相对单位

随浏览器视口尺寸变化，常用于响应式布局。调整窗口宽度或高度查看效果。

vw

1vw 等于视口宽度的 1%；下方色条宽度为 50vw。

vh

1vh 等于视口高度的 1%；色块高度为 12vh。

12vh

vmin 与 vmax

分别参照视口宽高中的较小值与较大值。方块边长为 20vmin。

20vmin
1vmax = 视口较大边的 1%
小提示：字号常用 rem，容器布局常结合 %、vw、vh 与 max-width 使用。
