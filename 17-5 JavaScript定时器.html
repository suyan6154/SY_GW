Chapter 17 · JavaScript 定时器

JavaScript 的两种定时器

JavaScript 提供两种定时器：延时定时器 setTimeout（到时间只执行一次） 和 间歇定时器 setInterval（每隔一段时间重复执行）。 它们都返回一个定时器编号，用 clearTimeout / clearInterval 可以随时取消。

一、setTimeout · 延时定时器（只执行一次）

3 秒倒计时炸弹：到点爆炸，中途可以拆除

点击「点燃引线」后，setTimeout 在 3000 毫秒后执行回调； 引燃期间点「拆除」（clearTimeout）可以取消它 —— 这是延时定时器最重要的配套操作。 

var sy_timerId = setTimeout(函数, 延时毫秒数);   // 返回定时器编号
clearTimeout(sy_timerId);                        // 取消还没执行的定时器
💣待命

二、setInterval · 间歇定时器（重复执行）

秒表：每 1 秒滴答一次，随时可以停

点击「启动秒表」后，setInterval 每 1000 毫秒执行一次回调，计数器不断 +1； 点「停止」（clearInterval）结束重复执行。 

var sy_timerId = setInterval(函数, 间隔毫秒数);   // 每隔一段时间执行一次
clearInterval(sy_timerId);                        // 停止重复执行

两种定时器对比

对比项 setTimeout 延时定时器 setInterval 间歇定时器
执行次数到时间后执行 1 次每隔指定时间执行，无限重复
返回值定时器编号（数字）定时器编号（数字）
取消方法clearTimeout(编号)clearInterval(编号)
典型用途延迟提示、防抖、动画补间时钟、轮播图、倒计时、轮询
共同点回调不是立刻执行，而是排入任务队列等主线程空闲；延时参数只是“最早执行时间”

提示：setTimeout(函数, 0) 也不会立即执行，它只是把回调排到当前代码执行完之后； 给回调传参可以写在延时参数后面：setTimeout(sy_fn, 1000, "参数1", "参数2")。 页面卸载或组件销毁时记得 clear，否则定时器会一直占用资源。
