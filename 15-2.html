程序结构：条件与循环

程序有三种基本结构：顺序（从上到下依次执行）、条件（按判断选择路径）、循环（重复执行代码块）。 本页通过可交互的演示，展示 if...else、switch 条件语句与 for、while 循环语句的用法。

一、条件结构（分支结构）

if...else 多分支 · 成绩等级判断

从上到下依次判断条件，命中一个分支后其余分支全部跳过。

if (sy_score >= 90)      { sy_grade = "优秀"; }
else if (sy_score >= 80) { sy_grade = "良好"; }
else if (sy_score >= 70) { sy_grade = "中等"; }
else if (sy_score >= 60) { sy_grade = "及格"; }
else                     { sy_grade = "不及格"; }

switch 语句 · 星期查询

对同一个变量的多个离散取值做精确匹配，记得用 break 结束分支。

switch (sy_day) {
    case 1: sy_name = "星期一"; break;
    ...
    case 7: sy_name = "星期日"; break;
    default: sy_name = "无效数字";
}

二、循环结构

for 循环 · 九九乘法表

双层 for 循环：外层控制行（sy_i），内层控制列（sy_j），列数不超过行号。

for (var sy_i = 1; sy_i <= 9; sy_i++) {
    for (var sy_j = 1; sy_j <= sy_i; sy_j++) {
        // 输出 sy_j × sy_i = 积
    }
}

while 循环 · 1~100 求和

先判断条件再执行循环体；循环体内必须改变条件变量，否则会死循环。

var sy_sum = 0, sy_n = 1;
while (sy_n <= 100) {
    sy_sum += sy_n;   // 累加
    sy_n++;           // 别忘了 sy_n++，否则死循环
}

循环 + 条件：break 与 continue

在 1~20 中输出所有偶数：奇数被 continue 跳过；当数字大于 14 时用 break 提前终止循环。

for (var sy_i = 1; sy_i <= 20; sy_i++) {
    if (sy_i % 2 !== 0) { continue; }  // 跳过奇数，直接进入下一轮
    if (sy_i > 14)      { break; }     // 终止整个循环
    sy_list.push(sy_i);                // 只有偶数会执行到这里
}

三种程序结构汇总

结构 关键语句 特点 适用场景
顺序结构 — 从上到下依次执行 一切程序的基础
条件结构 if...else、switch 按条件选择执行路径 等级判断、菜单选择
循环结构 for、while、do...while 重复执行，用 break / continue 控制流程 累加求和、遍历生成内容

提示：do...while 与 while 的区别是前者先执行一次再判断，循环体至少会执行一次。
