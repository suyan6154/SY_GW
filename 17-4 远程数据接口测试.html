三、测试要点

            

                
    
                    
  1. GET 用于读取数据，参数放在 URL 的 ? 后面；不能携带请求体。
    2. 
                    
  2. POST 用于新建数据，数据放在请求体里，通常需要 Content-Type: application/json。
    3. 
                    
  3. PUT / PATCH 用于修改数据：PUT 整体替换，PATCH 局部更新；DELETE 用于删除。
    4. 
                    
  4. fetch 只有网络层失败才会 reject（如断网、域名无法解析、跨域被拦截）；
                        HTTP 4xx / 5xx 属于“请求成功返回”，必须自己用 response.ok / status 判断。
    5. 
                    
  5. 跨域请求会被浏览器拦截，若接口未返回 Access-Control-Allow-Origin 头，
                        控制台会报 CORS 错误，本页会在错误区提示。
