六种基本数据类型

JavaScript 的数据类型分为简单类型（Number、String、Boolean、Undefined、Null） 和复杂类型（Object）。点击每张卡片中的「运行演示」按钮，即可查看 typeof 检测结果。

1

Number数值型

用于表示整数和小数（浮点数），也可以表示 NaN（非数字）和 Infinity（无穷大）。

var sy_age = 18;        // 整数
var sy_price = 9.9;     // 浮点数
var sy_pi = 3.14e2;     // 科学计数法
2

String字符串型

由单引号或双引号包裹的文本，可以用 + 进行拼接，通过 .length 获取长度。

var sy_name = "苏妍";
var sy_course = '高级网页设计';
var sy_msg = "你好，" + sy_name;
3

Boolean布尔型

只有 true（真）和 false（假）两个值，常用于条件判断，比较运算的结果也是布尔值。

var sy_isStudent = true;
var sy_isRaining = false;
var sy_result = 18 > 20;  // false
4

Undefined未定义型

变量只声明、未赋值时的默认类型，表示"还没有给出定义"。

var sy_unassigned;   // 未赋值
console.log(sy_unassigned);  // undefined
5

Null空型

表示"空的、不存在的对象"，通常主动用来清空变量。注意：typeof null 返回 "object"，属于历史遗留问题。

var sy_empty = null;
typeof sy_empty;        // "object"
sy_empty == undefined;  // true
6

Object对象型

六种类型中唯一的引用类型，用 { } 定义对象、[ ] 定义数组，通过属性名访问成员。

var sy_person = { name: "苏妍", age: 18 };
var sy_hobbies = ["读书", "编程", "设计"];

六种数据类型汇总

类型 类别 说明 示例 typeof 结果
Number 简单类型 整数、小数、NaN 18、9.9 "number"
String 简单类型 引号包裹的文本 "苏妍" "string"
Boolean 简单类型 真 / 假 true "boolean"
Undefined 简单类型 声明未赋值 var sy_x; "undefined"
Null 简单类型 空的对象指针 null "object"
Object 引用类型 对象、数组、函数等 { }、[ ] "object"

提示：前 5 种为基本（简单）类型，按值访问；Object 为引用（复杂）类型，按地址访问。
