移动端固定下导航（字体图标）

使用 font/ 目录下的 iconfont 字体图标制作一个固定在底部的四宫格下导航。图标本质是字体，可用 font-size、color 控制，并通过绝对定位叠加数字徽章与红点。

页面效果

导航固定在手机底部，内容可滚动，四个项目通过 flex: 1 平分宽度，随容器自适应。

关键代码

字体图标用 <i class="iconfont icon-*">，导航用 Flex 平分宽度并固定在底部。

<link rel="stylesheet" href="font/iconfont.css">

<nav class="su_tabbar">
  <div class="su_tab is-active">
    <i class="iconfont icon-a-shouyechangguishouye"></i>
    <span>首页</span>
  </div>
  <div class="su_tab">
    <i class="iconfont icon-faxian">
      <i class="su_badge su_dot"></i>
    </i>
    <span>发现</span>
  </div>
  <div class="su_tab">
    <i class="iconfont icon-xiaoxi">
      <i class="su_badge">5</i>
    </i>
    <span>消息</span>
  </div>
  <div class="su_tab">
    <i class="iconfont icon-a-wodedefuben2"></i>
    <span>我的</span>
  </div>
</nav>

.su_tabbar { position: absolute; bottom: 0; left: 0; right: 0; display: flex; }
.su_tab { flex: 1; position: relative; }
.su_tab .iconfont { font-size: 24px; position: relative; }
.su_badge { position: absolute; top: -6px; right: -12px; background: #ef4b5d; color: #fff; border-radius: 9px; }
.su_badge.su_dot { width: 9px; height: 9px; border-radius: 50%; right: -6px; }

字体图标优点：单色、可控性强、文件体积小；缺点：无法使用多色图标，且依赖字体文件加载。
