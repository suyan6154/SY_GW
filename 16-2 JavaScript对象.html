JavaScript 对象

对象是一组键值对（key: value）的集合，就像一张贴了标签的档案卡： 标签是属性名，内容是属性值。下面把对象画成档案卡，并交互演示 属性的读取、新增、修改、删除、遍历以及 this 与引用的特点。

一、认识对象：键值对档案卡

对象字面量写法

用一对花括号 { } 包住若干"键: 值"，键与值之间用冒号，条目之间用逗号。

var sy_student = {
    name: "苏妍",        // 字符串
    age: 20,             // 数字
    isMember: true,      // 布尔值
    courses: ["HTML", "CSS"],   // 值可以是数组
    sayHi: function () {        // 值可以是函数（方法）
        return "你好，我是" + this.name;
    }
};

另一种写法：先建空对象再挂属性

对象创建后属性可以随时增加，所以对象是"活的"，结构并不固定。

var sy_student = {};          // 或 new Object()
sy_student.name = "苏妍";      // 新增属性
sy_student["age"] = 20;       // 方括号也能新增

// 读取：两种写法结果相同
sy_student.name;              // "苏妍"
sy_student["name"];           // "苏妍"

三、遍历对象：把属性一个个取出来

三种常用遍历方式

for...in 拿到的是键；Object.keys / values / entries 分别拿到键数组、值数组、键值对数组。 

// 1. for...in：遍历键
for (var sy_k in sy_student) {
    console.log(sy_k, sy_student[sy_k]);
}

// 2. 三个静态方法（返回数组，更安全）
Object.keys(sy_student);      // ["name", "age", ...]
Object.values(sy_student);    // ["苏妍", 20, ...]
Object.entries(sy_student);   // [["name","苏妍"], ...]

四、对象方法：属性值可以是函数

方法与 this：谁调用，this 就指向谁

对象里定义的函数叫方法。方法内部用 this 指向"调用它的那个对象"， 所以 sy_counter.add() 里的 this 就是 sy_counter。 

var sy_counter = {
    count: 0,
    add: function () {
        this.count = this.count + 1;   // this 就是 sy_counter
        return this.count;
    },
    info: function () {
        return "当前计数：" + this.count;
    }
};
计数器当前值：0

五、对象是引用类型：赋值不复制内容

sy_b = sy_a：两个名字，同一张卡片

基本类型赋值是"复制内容"，对象赋值只是"复制了一个指向同一对象的地址"。 所以改 sy_b 其实就是改 sy_a。想要独立副本要用 Object.assign({}, 源对象) 或展开语法 {...源对象}。 

var sy_a = { score: 90 };
var sy_b = sy_a;                // 别名：指向同一个对象
sy_b.score = 100;               // sy_a.score 也变成 100

var sy_c = Object.assign({}, sy_a);  // 浅拷贝：独立的新对象
sy_c.score = 60;                // sy_a.score 仍然是 100

六、嵌套：对象里还能放对象和数组

多层结构：用"点"一路点下去

嵌套访问像走地址：sy_class.teacher.name 表示"班级 → 老师 → 姓名"。 数组元素用下标访问，例如 sy_class.courses[0]。

对象操作速查表

操作 语法 说明
创建对象var sy_o = { k: 1 };字面量最常用，也可 new Object()
读取（点）sy_o.k键名是合法标识符时使用，最直观
读取（方括号）sy_o["k"]键名有空格、含变量时使用
新增 / 修改sy_o.k = 2;键已存在就是改，不存在就是新增
删除属性delete sy_o.k;删除后该键不再存在
判断属性存在"k" in sy_o值为 undefined 时也能判断准确
遍历键for (var k in sy_o)拿到键，用 sy_o[k] 取值
键 / 值 / 键值对Object.keys / values / entries都返回数组，方便配合数组方法
转成 JSON 文本JSON.stringify(sy_o)用于存储或网络传输
从 JSON 解析JSON.parse(文本)把文本还原成对象
浅拷贝Object.assign({}, sy_o)嵌套对象仍然是共享引用

提示：sy_o 里没有的属性读取得到 undefined 而不是报错； 但继续往下点（如 sy_o.a.b）会报错，所以面试常问"如何安全访问深层属性"。
