Chapter 18 · SVG 应用

基于知识库的智能客服系统架构图

本图使用 SVG（可缩放矢量图形）绘制。与 Canvas 的"画完即忘"不同， SVG 的每个图形都是 DOM 节点，可以用 CSS 设样式、用 JS 绑事件、无限缩放不失真。 图中带 科研 标签的模块是本课题的研究重点（RAG、知识图谱、多轮对话、自动评测等）， 点击任意模块可查看说明。

科研方向

围绕本架构可开展的研究问题

  1. 检索增强生成（RAG）：研究混合检索（BM25 + 向量）权重、切块(Chunking)策略与重排模型对回答质量的影响，抑制大模型幻觉。
  2. 知识图谱与推理：研究电商领域本体构建、实体对齐与多跳推理查询，回答跨知识点的复杂问题（如跨店铺比价、组合售后政策）。
  3. 多轮对话状态跟踪（DST）：研究指代消解与槽位继承方法，让"它多少钱？""那退换货呢？"这类省略式追问也能被正确理解。
  4. 情感感知的服务策略：研究情绪识别如何驱动回复语气调整、优先级排序与人工转接时机，量化对满意度的影响。
  5. 自动评测与数据闭环：研究无参考答案场景下的回答质量自动评估方法，以及用户反馈数据的主动学习标注策略。

SVG 与 Canvas 对比（结合 18-2）

对比项SVG（本页）Canvas（18-2）
图形本质矢量 DOM 节点，永久保留在文档中位图像素，画完即忘
缩放表现无限缩放不失真，适合打印 / 大屏放大出现锯齿（需按 DPR 重绘）
事件交互每个图形可直接绑定 DOM 事件、支持 CSS :hover需手动做坐标命中测试（hit-test）
性能特点节点多时 DOM 开销大，适合静态示意图重绘效率高，适合大量粒子 / 游戏动画
适用场景架构图、图标、图表、地图动画、烟花、游戏画面、像素处理
