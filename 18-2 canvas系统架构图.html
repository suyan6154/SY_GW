Chapter 18 · Canvas 应用

电商全站系统架构图（Canvas 绘制）

Canvas 不只能做动画，也能画架构图、流程图这类示意图。 本页用 fillRect / arc / fillText / setLineDash 在画布上绘制电商系统的五层架构， 虚线箭头带流动动画表示请求方向；把鼠标悬停或点击任意模块可查看说明。

架构总览

用户层 接入层 服务层 中间件层 数据层 → 虚线箭头：请求 / 数据流向（自上而下）

绘制要点

这张架构图是怎么画出来的

  1. 圆角矩形：Canvas 原生没有圆角矩形，需要用 arcTo 或 quadraticCurveTo 自己封装一个函数。
  2. 分层布局：每一层是一个数据对象（标题、颜色、y 坐标、模块数组），用循环批量绘制，改数据就能改图。
  3. 流动箭头：setLineDash([8, 6]) 设置虚线，每帧改变 lineDashOffset，虚线就会"流动"。
  4. 文字：fillText 绘制，配合 textAlign 控制对齐；模块文字太长时截断加省略号。
  5. 交互：mousemove 时用 offsetX / offsetY 换算出画布坐标，逐一判断落在哪个模块矩形内，实现悬停高亮与提示框。
// 圆角矩形封装（核心片段）
function sy_roundRect(sy_ctx, x, y, w, h, r) {
  sy_ctx.beginPath();
  sy_ctx.moveTo(x + r, y);
  sy_ctx.arcTo(x + w, y, x + w, y + h, r);
  sy_ctx.arcTo(x + w, y + h, x, y + h, r);
  sy_ctx.arcTo(x, y + h, x, y, r);
  sy_ctx.arcTo(x, y, x + w, y, r);
  sy_ctx.closePath();
}

// 流动虚线（每帧执行）
sy_ctx.setLineDash([8, 6]);
sy_ctx.lineDashOffset = sy_dashOffset;   // sy_dashOffset 每帧递减
sy_ctx.stroke();
