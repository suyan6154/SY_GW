JSON 数据格式演示

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式， 长得像 JS 对象，但是一种纯文本。前端和服务器之间传数据， 基本都用 JSON。本页演示它的语法规则，以及两个核心方法： JSON.parse()（字符串 → 对象）和 JSON.stringify()（对象 → 字符串）。

一、JSON 的六种数据类型

一个 JSON 的值只能是下面六种之一：

string
"苏妍"
number
20 / 3.14 / -7
boolean
true / false
null
null
object
{ "key": 值 }
array
[ 值1, 值2 ]

JSON 的语法规则（比 JS 对象严格）

  1. 键必须用双引号包起来：{ "name": "苏妍" }，写成 { name: "苏妍" } 是非法的。
  2. 字符串值也只能用双引号，不能像 JS 一样用单引号或反引号。
  3. 不能写注释、不能有多余的逗号（最后一个键值对后面不能带 ,）。
  4. 不能出现 undefined、function，也不支持变量。
  5. 整个文件的最外层通常是 { }（对象）或 [ ]（数组）。

二、JSON.parse()：字符串 → 对象

解析学生数据

把下面这段 JSON 文本交给 JSON.parse()，它会变成真正的 JS 对象， 之后就能用 sy_student.name 这样访问了。 故意改错试试，会看到错误提示。 

JSON.parse(sy_jsonText);   // 解析失败会抛出 SyntaxError，必须 try...catch

三、JSON.stringify()：对象 → 字符串

把对象变成可传输的文本

发请求前要把 JS 对象转成字符串。注意： undefined 和 function 会被自动丢掉， null 会保留为 null。 

var sy_student = {
    name: "苏妍", age: 20,
    score: undefined,          // 会被丢弃
    sayHi: function () { }     // 会被丢弃
};
JSON.stringify(sy_student, null, 2);   // 第3个参数：缩进美化

四、往返转换（round-trip）

parse → stringify，数据不变

先 parse 成对象，再 stringify 回字符串 —— 只要格式合法，数据能完整还原，这就是 JSON 适合做数据交换的原因。

JSON 与 JS 对象字面量的区别

对比项 JS 对象字面量 JSON
键（属性名）引号可省略必须用双引号
字符串值单引号 / 双引号 / 反引号只能双引号
注释可以写不允许
结尾多余逗号允许不允许
undefined / 函数可以出现不允许
本质内存中的数据结构纯文本字符串
用途程序内部处理数据跨语言、跨网络传输数据

提示：fetch 从服务器拿到数据后，若响应头是 application/json， 用 response.json() 一步完成读取 + parse；普通文本则手动 JSON.parse(text)。
