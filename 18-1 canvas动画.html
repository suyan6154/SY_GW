Chapter 18 · Canvas 动画

Canvas 动画演示

Canvas 通过 JavaScript 每一帧重绘画面来实现动画：先用 fillRect / clearRect 清屏，再画新内容，配合 requestAnimationFrame 循环即可流畅播放。 下面三个演示分别展示小球物理运动、文字"苏妍"的彩色动画和可交互的粒子烟花。

一、弹跳小球

物理运动：位置更新 + 边界反弹

每帧给每个小球的坐标加上速度（vx, vy），碰到画布边缘就反转速度方向。

sy_ball.x += sy_ball.vx;                    // 每帧更新位置
if (sy_ball.x > sy_w - sy_ball.r || sy_ball.x < sy_ball.r) {
  sy_ball.vx = -sy_ball.vx;                 // 碰到左右边缘，水平速度反向
}

二、文字动画 · "苏妍"

弹跳文字 + 渐变色 + 拖影效果

"苏妍"两个字在画布中四处弹跳；每帧不完全清屏，而是盖上一层半透明背景， 就留下了漂亮的运动拖影；文字颜色按帧号循环变化。 

sy_ctx.fillStyle = "rgba(16,24,43,0.22)";   // 半透明背景
sy_ctx.fillRect(0, 0, sy_w, sy_h);          // 不完全清屏 → 产生拖影
var sy_grad = sy_ctx.createLinearGradient(sy_tx - 80, sy_ty - 60, sy_tx + 80, sy_ty);
sy_grad.addColorStop(0, "hsl(" + sy_hue + ", 90%, 65%)");
sy_ctx.fillStyle = sy_grad;
sy_ctx.font = "900 110px 'Microsoft YaHei'";
sy_ctx.fillText("苏妍", sy_tx, sy_ty);       // 绘制文字

三、粒子烟花（可交互）

点击画布任意位置，绽放一朵烟花

每个粒子有位置、速度、寿命：上升阶段受重力影响，寿命耗尽后透明度渐隐。 点击画布在鼠标位置生成 60 个随机方向的粒子。

提示：直接在画布上点击 / 触摸也可以发射，位置跟随鼠标。

Canvas 动画要点

  • 动画三步曲：清屏 → 更新物体状态（坐标、速度）→ 重绘，循环往复。
  • requestAnimationFrame：让浏览器在下次重绘前调用回调（约 60 帧/秒），比 setInterval 更流畅省电；页面切到后台会自动暂停。返回的帧 ID 可用 cancelAnimationFrame 停止。
  • 拖影效果：用半透明颜色盖一层背景代替完全清屏，旧画面就会慢慢"淡出"。
  • 渐变与发光：createLinearGradient 制作填充渐变，shadowColor + shadowBlur 制作发光。
  • 交互：给 canvas 元素绑定 click / mousemove 事件，用 offsetX / offsetY 得到画布内坐标。
