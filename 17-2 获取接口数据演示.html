Chapter 17 · fetch 与接口数据

fetch 获取接口数据

使用原生 fetch 从跨域接口 dummyjson.com 获取真实商品数据： 先加载 8 条商品列表，再点击任意商品，通过 详情接口 按 ID 查询完整信息。 该接口服务器已开启 CORS，允许浏览器跨域访问。

一、接口信息

列表接口

GET https://dummyjson.com/products?limit=8

详情接口

GET https://dummyjson.com/products/{id} 
fetch(sy_url)                    // 1. 发起请求，返回 Promise
    .then(function (sy_res) {
        if (!sy_res.ok) {            // 2. 检查 HTTP 状态码（fetch 不会自动报错）
            throw new Error("HTTP " + sy_res.status);
        }
        return sy_res.json();        // 3. 把响应体解析成 JS 对象（也是 Promise）
    })
    .then(function (sy_data) {       // 4. 拿到数据，渲染页面
        console.log(sy_data.products);
    })
    .catch(function (sy_e) {         // 5. 网络错误、解析错误都在这里捕获
        console.error(sy_e);
    });

三、本例要点

  1. fetch 是原生方法，基于 Promise，不用引入任何库就能发 HTTP 请求。
  2. fetch() 返回的 Promise 在收到响应头时就完成，所以必须用 sy_res.ok / sy_res.status 手动判断 404、500 等状态。
  3. sy_res.json() 负责把响应文本按 JSON 解析成对象，对应第 17-1 页学到的 JSON.parse()。
  4. 跨域（CORS）：浏览器默认阻止跨域读取响应，本例接口响应头带有 Access-Control-Allow-Origin: *，所以可以直接访问。
  5. 所有网络操作都要用 catch 兜底：断网、超时、接口出错时页面给出提示，而不是崩溃。
