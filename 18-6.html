Chapter 18 · Three.js 3D 可视化

Three.js 3D 图表

Three.js 是 WebGL 3D 引擎，配合"场景 → 相机 → 渲染器"三件套把数据画到立体空间里。 本页两个图表均纯代码建模（无外部模型文件）： ① 3D 柱状图——BoxGeometry 按数据缩放高度，拖拽旋转、滚轮缩放、 Raycaster 悬停显示数值； ② 3D 饼图——CylinderGeometry 按占比切片，悬停扇块自动"弹出"，可自动旋转。 库文件已按项目规则下载到本地 cdn/ 目录。

一、3D 柱状图（商城上半年销量）

拖拽旋转视角 · 滚轮缩放 · 悬停查看数值

每根柱子是一个 BoxGeometry 立方体，高度与销量成正比， 颜色按数值深浅渐变（HSL）；底座平面 + GridHelper 网格辅助定位， 轴标签用 Canvas 画的文字贴图（Sprite）始终朝向相机。

数码 服饰 食品 柱子颜色越亮 = 销量越高

操作：按住鼠标左键拖拽旋转，滚轮缩放，悬停柱子查看数值。

// 三件套：场景、相机、渲染器
var sy_scene = new THREE.Scene();
var sy_camera = new THREE.PerspectiveCamera(45, sy_w / sy_h, 0.1, 100);
var sy_renderer = new THREE.WebGLRenderer({ antialias: true });
sy_renderer.setSize(sy_w, sy_h);

// 数据 → 几何体：高度与数值成正比
var sy_h = sy_value / 100 * 4;
var sy_mesh = new THREE.Mesh(
  new THREE.BoxGeometry(0.6, sy_h, 0.6),
  new THREE.MeshLambertMaterial({ color: sy_color })
);
sy_mesh.position.set(sy_x, sy_h / 2, sy_z);   // 底部对齐地面

// Raycaster 拾取：鼠标位置 → 射线 → 命中的柱子
sy_raycaster.setFromCamera(sy_mouseNDC, sy_camera);
var sy_hits = sy_raycaster.intersectObjects(sy_barGroup.children);

二、3D 饼图（商城类目销售占比）

悬停扇块弹出 · 自动旋转可开关

每个扇块用 CylinderGeometry(顶半径, 底半径, 高, 分段, 1, false, 起始角, 弧度) 的扇形参数生成，弧度 = 占比 × 2π；悬停时扇块沿自身角平分线方向"弹出"， 下方提示框显示占比。 

// 扇形 = 圆柱体的一段弧，弧长由占比决定
var sy_angle = sy_value / sy_total * Math.PI * 2;
new THREE.CylinderGeometry(
  3, 3, 1.2, 64, 1, false,
  sy_startAngle,       // 起始角
  sy_angle             // 本扇块的弧度
);

// 悬停弹出：沿角平分线方向平移 0.4
var sy_mid = sy_startAngle + sy_angle / 2;
sy_mesh.position.set(Math.sin(sy_mid) * 0.4, 0, Math.cos(sy_mid) * 0.4);

Three.js 要点

  • 三件套：Scene（舞台）+ PerspectiveCamera（透视相机，视野角 45°）+ WebGLRenderer（渲染器），每帧调用 renderer.render(scene, camera)。
  • 光照：MeshLambertMaterial 受光影响，需要 AmbientLight 环境光 + DirectionalLight 方向光，否则物体全黑。
  • 用数据建模：柱高 = 数值 / 最大值 × 单位高度；饼图弧度 = 占比 × 2π —— 3D 图表的本质是"数据驱动几何体参数"。
  • 交互拾取：Raycaster 从相机向鼠标位置发射线，intersectObjects 返回命中物体，实现 3D 版的"悬停"。
  • 文字贴图：Three.js 没有文字节点，用 Canvas 画字 → CanvasTexture → Sprite，Sprite 永远面向相机，适合做轴标签。
  • 自适应：监听 resize，同步更新相机宽高比 camera.aspect 与 renderer.setSize。
