Lucide SVG 图标

Lucide 以 SVG 矢量的方式提供图标：它把图标作为内联 SVG 插入页面，颜色跟随 currentColor，可以直接用 CSS 控制描边、大小和动画。

基础图标

使用 <i data-lucide="*">，再调用 lucide.createIcons() 渲染为 SVG。

状态与颜色

SVG 使用 stroke="currentColor"，颜色随父元素 color 变化，也可用 stroke-width 调整线条粗细。

直接内联 SVG

除了用 data-lucide 自动生成，也可以直接把 SVG 代码写进 HTML，完全不依赖 JavaScript。
