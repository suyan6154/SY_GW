二、迭代方法（对每个元素做事情）

forEach · 逐个访问

像老师点名：把每个元素依次交给你处理，没有返回值。

sy_arr.forEach(function (sy_item, sy_i) {
    console.log(sy_i, sy_item);
});

map · 逐个加工，返回新数组

像流水线：每个元素被加工后放进新数组，原数组不变。

var sy_new = sy_nums.map(function (sy_n) {
    return sy_n * 10;
});

filter · 按条件筛选

像过筛子：条件为真的留下，为假的被筛掉，返回新数组。

var sy_big = sy_nums.filter(function (sy_n) {
    return sy_n > 7;   // 只留下大于 7 的
});

reduce · 归并为一个值

像滚雪球：带着上一步的结果继续累加，最后只剩一个值。

var sy_sum = sy_nums.reduce(function (sy_acc, sy_n) {
    return sy_acc + sy_n;
}, 0);

数组方法速查表

方法 作用 是否改变原数组 返回值
push()末尾添加一个或多个元素改变新长度
pop()删除并返回末尾元素改变被删的元素
unshift()开头添加一个或多个元素改变新长度
shift()删除并返回开头元素改变被删的元素
splice()任意位置删除 / 插入 / 替换改变被删元素组成的数组
reverse()翻转数组顺序改变翻转后的数组
sort()排序（默认按字符串比较）改变排序后的数组
slice()截取 [start, end) 片段不改变新数组
concat()拼接多个数组或值不改变新数组
join()用分隔符把元素连成字符串不改变字符串
indexOf()查找元素首次出现的下标不改变下标，找不到返回 -1
includes()判断是否包含某元素不改变true / false
forEach()遍历每个元素执行函数不改变undefined
map()对每个元素加工不改变新数组
filter()筛选满足条件的元素不改变新数组
reduce()从左到右归并为一个值不改变累计结果

提示：sort() 默认把元素转成字符串再按字典序比较，所以 [1, 5, 10].sort() 会得到 [1, 10, 5] 而不是 [1, 5, 10]。数字排序要传比较函数： sort(function(a, b){ return a - b; })。
