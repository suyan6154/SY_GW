Chapter 18 · Mermaid 图表即代码

智能客服系统：流程图与 ER 图

Mermaid 是"图表即代码"（Diagram as Code）工具：用一段类似 Markdown 的文本描述图表， 库会自动渲染成 SVG。相比手绘 SVG / Canvas，文本源码易版本管理、易修改， 非常适合画架构图、流程图、ER 图这类工程图表。 本页以 18-3 的智能客服系统为背景，绘制问答业务流程图与数据库 ER 图， 可点击各图下方的"查看源码"对照学习。

二、智能客服系统数据库 ER 图

erDiagram：七张核心表的实体关系

一个用户可发起多个会话，每个会话包含多条消息；每条消息可产生反馈数据， 并可关联命中的知识条目（多对多）；知识条目按分类组织，订单与消息关联支撑"查订单"场景。 ||--o{ 表示一对多，}o--o{ 表示多对多。

ER 图关系符号速查

符号含义示例解读
||--o{一对多（左 1 右多）一个用户发起多个会话
}o--o{多对多一条消息可命中多个知识条目
|o--o{零或一对多一条消息可以不关联订单，也可以关联
||--||一对一每个员工对应一张工牌

Mermaid 要点

  • 使用方式：mermaid.initialize({ startOnLoad: true }) 后，把图表源码写在 <pre class="mermaid"> 中即可自动渲染为 SVG。
  • 节点形状：[矩形]、(圆角)、{菱形判断}、([体育场])、[(数据库圆柱)]，形状自带语义。
  • 连线样式：实线 -->、粗线 -->>、虚线 -.->，线上文字用 --|文字|。
  • 含特殊字符的文本：节点文字建议写在双引号里（如 ["置信度达标?"]），问号、斜杠才不会被解析器误认。
  • ER 图属性：每行"类型 名称 主外键(可选) 注释(可选)"，PK=主键、FK=外键；本页 vector embedding 字段对应 18-3 知识库的语义检索设计。
  • 图表即代码：源码可进 Git 版本管理、可评审、可 diff，与手绘图相比改起来只需改一行文字。
