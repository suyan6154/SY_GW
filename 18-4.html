Chapter 18 · ECharts 数据可视化

ECharts 图表演示

ECharts 是百度开源的图表库。本页演示两个官方经典案例： ① 地理坐标系上同时绘制冰岛等值区划图（choropleth）与散点图， 用两个 visualMap 分别映射区域颜色与散点大小； ② 使用 echarts.graphic.LinearGradient 实现渐变堆叠面积图。 两个库文件已按项目规则下载到本地 cdn/ 目录，无外链请求。

一、地理坐标系：等值区划图 + 散点图（冰岛）

map 系列渲染区域数值，scatter 系列渲染城市散点

拖动 / 滚轮可缩放地图；左下角视觉映射控制各区域颜色，右下角控制散点大小； 悬停查看数值。关键点：geo 组件提供地图坐标系， map 与 scatter 两个系列都通过 geoIndex: 0 共享它。 

// 1. 注册地图：GeoJSON 已封装在 cdn/iceland-geo.js 中（window.sy_icelandGeo）
echarts.registerMap("sy_iceland", window.sy_icelandGeo);

// 2. aspectScale 按纬度修正墨卡托变形（冰岛约北纬 65°）
geo: {
  map: "sy_iceland",
  roam: true,
  aspectScale: Math.cos((65 * Math.PI) / 180)
}

// 3. 两个系列共享 geo 坐标系，避免重复创建
{ type: "scatter", coordinateSystem: "geo", geoIndex: 0, ... }
{ type: "map",     geoIndex: 0, data: [{ name: "Austurland", value: 423 }, ...] }

// 4. visualMap 用 dimension 指定映射的数据维度
visualMap: { seriesIndex: 0, dimension: 2, inRange: { symbolSize: [5, 30] } }
visualMap: { seriesIndex: 1, dimension: 0, inRange: { color: ["#deebf7", "#3182bd"] } }

二、渐变堆叠面积图

5 条 line 系列共用 stack: "Total" + 线性渐变填充

面积堆叠的秘密：stack 值相同的系列会逐层累加； 把 lineStyle.width 设为 0、隐藏 symbol，就只剩渐变"色带"； 渐变颜色由 echarts.graphic.LinearGradient 从上到下过渡。 悬停可查看每层数值，右上角工具栏可保存为图片。 

areaStyle: {
  opacity: 0.8,
  color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
    { offset: 0, color: "rgb(128, 255, 165)" },   // 顶部颜色
    { offset: 1, color: "rgb(1, 191, 236)" }      // 底部颜色
  ])
},
lineStyle: { width: 0 },    // 隐藏描边线
showSymbol: false           // 隐藏数据点

ECharts 要点

  • 引入方式：本项目不使用外链 CDN，库文件下载到 cdn/echarts.min.js 后用本地 <script> 引入。
  • 初始化三步：echarts.init(dom) → 编写 option 配置对象 → setOption(option)；数据变化时再次 setOption 即可增量更新。
  • registerMap：地理数据本质是 GeoJSON（FeatureCollection），注册后即可被 geo / map 系列使用。
  • visualMap：视觉映射组件，把数据维度映射为颜色 / 大小等视觉通道；多个 series 时用 seriesIndex 绑定。
  • encode：声明"数据维度 → 视觉通道"的对应关系，如 tooltip: 2 表示第 3 维数据显示在提示框。
  • 自适应：监听 window.onresize 调用 chart.resize()，让图表跟随容器缩放。
